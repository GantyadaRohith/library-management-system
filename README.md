# Library Management System

A full-stack application for managing library books, requests, and user accounts (students and librarians) using React, Express, and MongoDB.

## Structure
- `/client`: React frontend
- `/server`: Express backend
- MongoDB: Database

## Features
- List available books
- Student and librarian accounts
- Book request queue
- Librarian management and email notifications

## Getting Started
1. Install dependencies in `/client` and `/server`
2. Configure MongoDB connection in `/server`
3. Run both frontend and backend
